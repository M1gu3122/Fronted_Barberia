# Proton Barber - Frontend

Estructura de proyecto para la barbería Proton Barber con Tailwind CSS, HTML y JavaScript puro.

## Estructura de carpetas

```
proton-barber/
├── index.html                 # Página de login principal
├── css/
│   └── styles.css             # Estilos principales
├── js/
│   └── login.js               # Lógica de login
├── assets/
│   ├── images/                # Imágenes de la aplicación
│   └── icons/                 # Iconos
└── components/                # Componentes reutilizables
    └── login-form.html        # Componente de formulario de login
```

## Características

- Diseño responsive con Tailwind CSS
- Interacción de usuario con JavaScript puro
- Componentes reutilizables
- Estilos personalizados con Tailwind
- Validación de formularios
- Estado de carga durante las llamadas API

## Tecnologías utilizadas

- HTML5
- CSS3 (Tailwind CSS)
- JavaScript ES6+
- Font Awesome (para iconos)

## Cómo ejecutar

1. Abre `index.html` en tu navegador
2. El proyecto está completamente funcional con Tailwind CSS

## Estructura de archivos

### index.html
- Página de login completa
- Formulario de autenticación
- Botones de inicio de sesión social

### css/styles.css
- Estilos personalizados
- Clases Tailwind extendidas
- Estilos responsive

### js/login.js
- Lógica de validación de formularios
- Manejo de eventos de clic
- Simulación de llamadas API
- Estado de carga

### assets/
- Recursos estáticos (imágenes, iconos)

### components/
- Componentes reutilizables para la interfaz

## Configuración

El proyecto utiliza Tailwind CSS con configuración personalizada para el diseño de la barbería Proton Barber.

## Personalización

Para personalizar el estilo:
1. Modifica `tailwind.config.js` para cambiar colores y temas
2. Edita `css/styles.css` para nuevos estilos
3. Actualiza `js/login.js` para nueva lógica de negocio
