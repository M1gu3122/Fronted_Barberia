# Design: Barbería El Corte Perfecto

## Design Philosophy

This design reflects the premium, traditional yet modern approach of Barbería El Corte Perfecto. The aesthetic combines classic barber shop sophistication with contemporary clean design principles.

## Color Palette

- Primary: #121414 (Dark charcoal)
- Secondary: #C5A059 (Warm golden brown)
- Accent: #E9C176 (Light gold)
- Text: #E2E2E2 (Light gray)
- Background: #FFFFFF (White)

## Typography

- Headings: Playfair Display (Elegant serif font)
- Body Text: Hanken Grotesk (Modern sans-serif)

## Layout Principles

- Clean, spacious design with ample white space
- Professional yet approachable aesthetic
- Easy navigation and clear visual hierarchy
- Responsive layout for all device sizes

## Component Design

### Header
- White background with dark text
- Elegant typography
- Navigation with hover effects
- Minimalist design

### Hero Section
- Dark background (#121414) with text overlay
- Large, bold typography
- Prominent call-to-action button
- Minimalist composition

### Services Section
- Clean card-based layout
- Consistent styling for all service cards
- Subtle shadows for depth
- Responsive grid layout

### Footer
- Dark background (#121414)
- Centered layout with social media links
- Copyright information
- Professional presentation

## Interactive Elements

- Subtle hover effects on navigation and buttons
- Smooth transitions for interactive elements
- Clear visual feedback on user actions
- Consistent design language throughout

## Responsive Design

- Mobile-first approach
- Flexible grid system
- Adaptable typography
- Touch-friendly elements
- Optimized for all screen sizes

## Accessibility

- WCAG 2.1 AA compliance
- Sufficient color contrast
- Semantic HTML structure
- Keyboard navigation support
- Screen reader friendly
